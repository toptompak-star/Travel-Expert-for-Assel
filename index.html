Как считаем и откуда данные

Соответствие направления

Средневзвешенная оценка по ночам поездки: если поездка захватывает два месяца, климат и сезон считаются пропорционально числу ночей в каждом.

Сезон 20% Погода 22% Тип отдыха 23% Дети 12% Бюджет 13% Перелёт 10%

Без детей вес «Дети» распределяется между остальными факторами. Для пляжного отдыха учитывается температура моря: от 24° — 100%, 22–23° — 80%, 20–21° — 50%.

Релевантность отеля

Когда подключён Booking Demand API, в основную подборку попадают только отели с оценкой 8.0+ и, если есть выбор, с включённым завтраком. Оценка корректируется на число отзывов (байесовское среднее, априорно 8.2 при весе 800 отзывов).

Пример из ТЗ: 9.1 и 350 отзывов → надёжная оценка 8.47; 8.8 и 8 500 отзывов → 8.75. Второй отель выше, но решает не только это.

Надёжная оценка 28% Отзывы 17% Транспорт 22% Завтрак 13% Цена 10% Центр 5% Семья 5%

Транспорт важнее центра

Для каждого вида транспорта считается балл: до 300 м — 100%, дальше линейно до нуля на 1,5 км. Вес: метро 1.0, трамвай 0.92, крупная остановка 0.78, вокзал 0.72. В итог берётся лучший вариант, а близость к центру весит всего 5%.

Подключение реальных данных

  • getCityImages()REAL · Wikimedia Commons
  • getHotelBookingUrl()REAL · страница отеля на Booking.com + даты
  • getHotelImages()Commons, где есть · прод: Booking Demand API
  • getHotelDetails()прод: Booking Demand API (рейтинг, отзывы, тарифы)
  • getFlightOffers()DEMO · прод: Aviasales / Amadeus / Duffel
  • getTransportData()прод: OpenStreetMap Overpass

Каждая функция — единственная точка подключения: замена её тела не требует переделки интерфейса.

Фотографии

Города: 3–4 реальных файла Wikimedia Commons на каждый город, с подписью и ссылкой на страницу файла (автор и лицензия). Отели: открытые фото здания из Commons есть у Pera Palace, Hotel Paris Prague, Casa Fuster и Sheraton Batumi; для остальных — кнопка на фото отеля в Booking.com. Сгенерированные и чужие изображения не используются.
